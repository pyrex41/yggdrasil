# Shen-C native RC integration, 2026-10-18

The C target now uses **Shen-C v0.3.0's `rc-build` and independent C17 RC
runtime**. It preserves manifest-selected files, explicit initialization and
declared user arities. The removed `libshenc.a`/`yggdrasil-build` interface,
Boehm/pkg-config requirement and automatic Nix re-entry are replaced. The
general shell also drops its explicit Boehm package.

Branch `fix/shen-c-native-rc` is based on `3ac17621`. Yggdrasil still shakes its
pinned community **42.2** kernel using a compatible host. Shen-C's own CLI
bundles a separate S43 kernel reported as **43.1**; that kernel is not
substituted into the artifact.

The previous builder consumed `fn=` declarations; `rc-build` ignores them.
The adapter stages byte-preserving copies and prepends KL `put` operations
after kernel initialization, before user code. This registers arities without
retaining optional source-reflection helpers. A real user arity probe changed
from `-1` to **`1`**, including through the packaged Nix CLI.

## Open dynamic-load slice

The **shaken** `tc-interp` artifact still omits `fix`, called by the interpreter
it loads at runtime. Its handler catches the error, so exit zero is not a
passing oracle: stdout reports `undefined function fix`. This dependency
closure remains **OPEN**. The same program with `--no-shake` typechecks and
returns `normal-form = 7`, demonstrating the native compiler/evaluator works
with the full kernel. Use that mode until the dynamic dependency set is closed.

## Reproduction and evidence

Set `YGGDRASIL_HOST` to a Shen-Go 42.2 launcher and `YGGDRASIL_SHEN_C_DIR` to
a Shen-C v0.3.0 source checkout:

```sh
go build -o .bin/ygg .
go test -tags shen_c -count=1 -run TestCBuilder -v .
.bin/ygg run tests/hello.shen out-rc-hello --target c
.bin/ygg run tests/fib.shen out-rc-fib --target c
.bin/ygg build tests/tc-interp.shen out-rc-tc-full --target c --no-shake
nix build .#yggdrasil
```

Run the last native executable from `tests/`, where `interpreter.shen` lives;
require the exact `normal-form = 7` line. For default unit scope, unset host
variables and run `go test -count=1 ./...`, retaining the reported skips.
